componentType: default
---

* PostgreSQL version 17 and lower.
* A New Relic account. Don't have one? [Sign up for free!](https://newrelic.com/signup) No credit card required.

**Network requirements**

* The New Relic infrastructure agent must be able to connect to your Aurora cluster endpoint
* Your Aurora cluster's security group must allow inbound traffic on the PostgreSQL port (default: 5432) from the infrastructure agent
