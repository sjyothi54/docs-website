headingText: Enable query monitoring for Aurora/RDS
componentType: default
---

Follow these instructions to enable query monitoring for Aurora or RDS PostgreSQL.

### Configure Database Parameter Groups

1. Navigate to your RDS or Aurora PostgreSQL instance in the AWS Management Console.

2. Select or create a custom parameter group:
   * **Create new**: Choose the appropriate parameter group family that matches your database engine version (e.g., for Aurora PostgreSQL use `aurora-postgresql16`).
   * **Modify existing**: Edit existing custom DB parameter groups associated with your Aurora/RDS DB setup.
   > **Important**: Do not modify the default parameter group, as default groups are immutable; creating a custom group allows for settings changes.

3. Configure the DB Parameter Groups by setting the following parameters:
   ```
   shared_preload_libraries = 'pg_stat_statements'    # Enable query monitoring
   pg_stat_statements.track = 'all'                   # Track all statements
   track_activity_query_size = 2048                   # Increase if you have long queries
   pg_stat_statements.max = 10000                     # Maximum number of statements to track
   ```

4. Associate the parameter groups:
   * Select your DB cluster and instance in the RDS console
   * Click **Modify**
   * Find the DB instance parameter group and DB cluster parameter group settings
   * Apply your new or modified parameter groups

5. Reboot your Aurora DB instance for the changes to take effect

> **Note**: For more information, refer to the [Working with DB Parameter Groups](https://docs.aws.amazon.com/AmazonRDS/latest/UserGuide/USER_WorkingWithParamGroups.html) section of the AWS documentation.


### Enable Extension and Set Permissions

1. Connect to your PostgreSQL instance using the psql command line tool or any PostgreSQL client.

2. Enable the pg_stat_statements extension in the database where you want to monitor query performance:
   ```sql
   CREATE EXTENSION IF NOT EXISTS pg_stat_statements;
   ```
